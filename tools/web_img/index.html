镜像烧录方法

1

准备一张 16GB 以上的高速 TF 卡（建议 Class 10）。

2

下载并安装烧录工具，如 Etcher 或 Rufus。

3

解压下载的镜像文件，并使用工具将其写入 TF 卡。

4

将 TF 卡插入 K230 板卡插槽，拨动启动开关至 SD 卡启动位。

注意事项

  • 请核对 SHA256 校验码，确保镜像文件完整。
  • 烧录过程中请勿拔掉读卡器，避免卡片损坏。
  • 首次启动可能需要几分钟进行文件系统扩容，请耐心等待。
  • 若无法启动，请检查电源供电（建议 12V/2A 以上）。
